## アイテムデータ

データソース: `Assets/Database/DungeonBluePrintData/Dungeon.asset`（出現プール）、`MapGraph.asset`（ボス報酬）、`Assets/Database/ItemData/`（武器定義）。

### 出現プール一覧

マスターデータ上、各アイテムがどのプールに登録されているか。○ = 登録あり。

- **通常**: フロアに落ちるアイテム（`SpawnItem` カテゴリ重み付き抽選）
- **宝箱**: 宝箱の中身（`ChestItems` 等。フロアの `WeaponChanceInChest` により通常武器プールから武器が出る場合あり）
- **ボス**: ボス撃破後の報酬宝箱（`MapGraph` の `_bossReward`）
- **店**: ショップの品揃え（`ShopItems`）

### 武器能力（ItemFeature）一覧

| 能力名 | 説明 |
|---|---|
| 2マス攻撃 | 攻撃範囲が直線2マスになる（通常は1マス） |
| 扇型攻撃 | 攻撃範囲が扇形になる |
| 回転攻撃 | 攻撃範囲が周囲（回転攻撃）になる |

| 能力名 | 説明 |

| 爆発 | 命中地点と周囲1マスに爆発範囲攻撃 |

### 武器接頭辞（プレフィックス）

武器名の前に付く修飾語。能力（ItemFeature）とは別枠で、武器の基礎性能や上限値を補正する。

- **付与タイミング**: 宝箱の中身が武器枠になったとき、`WeaponPrefixes` から1つ抽選される。
- **対象**: 近接武器・射撃武器。通常ドロップ、店売り、ボス固定報酬、シャイニー敵の所持武器には通常付かない。
- **現状の出現**: 各 `FloorData` の `WeaponChanceInChest` が 0 の場合、宝箱から接頭辞付き武器は出ない。
- **呪い付き**: 接頭辞の `IsCursed` が有効な場合、その接頭辞が付いた武器は生成時に呪われる。
- **表示名**: `接頭辞名 + 武器名` で表示される（例: `鋭いロングソード`）。
